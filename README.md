# HEH-Play

The games page from Homework Launchpad, at **play.civilinitiatives.org**: every game
in one place - the learning games, the Scratch games (games.civilinitiatives.org),
the Arcade (arcade.civilinitiatives.org) and the doodles (doodles.civilinitiatives.org).

Accounts with only the learning games switched on see just those. Accounts with
games switched off get the site's 404 page. Sign-in and the games lock come from
the main site, civilinitiatives.org.
